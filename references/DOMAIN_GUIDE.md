# 作业负担与有效性审查领域指南

## 业务问题

各学科独立布置作业，单科看似合理，累计后可能超时；重复抄写和低效任务也会侵蚀学习时间。

## 产品解决方案

按年级、学科和周期汇总作业，估算时间并审查任务与目标对齐、重复度、可完成性和反馈价值。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `assignments` | 跨学科作业清单 | 是 | 学科、任务、目标、预计用时和提交方式 |
| `grade` | 年级 | 是 | 用于年龄与教学常规边界 |
| `student_group` | 学生群体 | 是 | 班型与学习差异摘要 |
| `learning_objectives` | 目标 | 是 | 作业应服务的学习目标 |
| `parent_feedback` | 家长反馈摘要 | 否 | 脱敏后的负荷反馈 |
| `schedule_context` | 周内时间安排 | 是 | 考试、假期和活动周 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

完成时间必须基于真实样本和教师确认；“减负”不能损害课程必要目标；避免一刀切。
